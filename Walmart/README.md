# Walmart Stores

## Project
How well did Walmart stores perform during the period 1/10/2010 to 12/10/2012?

## Data
- [Kaggle Walmart Dataset](https://www.kaggle.com/datasets/yasserh/walmart-dataset/data)

## Tools
Power BI (DAX, Data Model, Slicers)

## Insights
- Average Daily Sales: $1,047,000
- Number of Stores: 45
- Holiday events contributed ~7.5% ($505,000,000) to overall sales
- Fuel Price, CPI, and Unemployment did not seem to have a noticable impact on sales
- Store 20 had the highest sales, $301,400,00
- Store 33 had the lowest sales, $37,000,000
- Sales peak in November & December
- Sales are the lowest at the end of January
